Beep.AI.Code Documentation

Terminal-native coding assistant CLI — authenticates with Beep.AI.Server, streams completions, runs autonomous agents with local tools, and supports RAG, MCP, plugins, and multi-provider backends

Overview

Beep.AI.Code is the official CLI companion for Beep.AI.Server's coding assistant. It talks to Beep.AI.Server the same way OpenAI Codex CLI talks to OpenAI's API or Claude Code talks to Anthropic. You authenticate with an application API token, stream completions, and optionally attach Coding Assistant workspace metadata so the server can run the same tools, sessions, and policies as the web assistant. This is your private stack — you run your server; the CLI does not ship models.

Architecture

CLI Layer

Typer + Rich terminal UI. Delegates command behavior to beep/commands/* modules: chat, ask, agent, review, test, workspace.

beep/cli.py, beep/commands/

API Transport

Async httpx client with SSE streaming. OpenAI-compatible chat completions + Coding Assistant bootstrap, RAG, and diagnostics endpoints.

beep/api/client.py

Agent Runtime

Autonomous agent with local tools (read, search, edit, shell), provider plugins (OpenAI, Anthropic, OpenRouter, LM Studio, Ollama), structured output, and MCP subprocess tools.

beep/agent/

Chat REPL

Interactive slash-command REPL with streaming responses, @file mentions, pinned context, git-aware hints, and Coding Assistant bootstrap integration.

beep/chat/repl.py

Features

Interactive Chat

Default beep / beep chat — streaming replies, slash commands, @file mentions, pinned context, git-aware hints, and Coding Assistant bootstrap.

One-Shot Prompts

beep "question" or beep ask "question" for non-interactive prompt execution.

Autonomous Agent

beep agent with local tools (read/search/edit/shell), step limits, -y auto-approve, structured output, multimodal input (text + images), and provider configuration.

Plugins

Optional workspace and user plugins. Use --no-plugins for untrusted repos. Provider plugins support custom backends.

Workspace Utilities

tree, cat, grep, edit for scripts and automation from the terminal.

Quality & Diagnostics

test, lint (with --fix), review (with --staged), analyze, diagnostics, status.

Templates, Sessions, RAG

List/generate templates, manage sessions, query RAG collections — server capabilities and token scopes permitting.

Full TUI + Watcher

beep tui for full terminal UI. beep watch to run commands on file changes. Shell completions via --install-completion.

Installation

pipx (Recommended)

pipx install "git+https://github.com/The-Tech-Idea/Beep.AI.Server.git#subdirectory=Beep.AI.Code"

From local checkout

pip install -e ".[dev]"          # Development
pipx install .                     # Isolated install

From built artifact

pip install dist/*.whl
pipx install dist/*.whl

Requirements: Python 3.11+, running Beep.AI.Server, application API token with llm:*, agent:*, rag:* scopes.

First-Time Setup

Setup wizard

beep setup

You will be prompted for Server URL, API token, and optional default model. Config stored at ~/.beepai/code.json (file mode 0600).

BEEP_PROJECT_IDCoding Assistant project ID

Daily Usage

Interactive Chat

beep                           # Start REPL
beep chat                      # Same as above
beep chat --no-plugins         # Skip loading local plugins

One-Shot Question

beep "How does authentication flow through the middleware?"
beep ask "Summarize beep/api/client.py"

Autonomous Agent

beep agent "Add type hints to beep/config.py" --max-steps 15
beep agent "Run tests and fix failures" -y          # Auto-approve
beep agent "Extract failing tests" --response-json  # Structured output
beep agent "Review this design" --input-file notes/design-brief.md

Agent Providers

beep agent providers      # List available providers
beep agent status         # Active provider + capabilities
beep agent configure openai
beep agent configure anthropic
beep agent configure openrouter

MCP Tools

beep mcp presets
beep mcp init playwright --preset playwright
beep mcp verify-tools playwright --discover

Workspace Utilities

beep tree . --depth 4
beep cat path/to/file.py --start 1 --end 80
beep grep "TODO" src/
beep edit path/to/file.py --content "..." --yes

Quality & Diagnostics

beep test
beep lint --fix
beep review --staged
beep analyze .
beep diagnostics
beep doctor                  # Config, runtime, and session checks
beep doctor --fix            # Auto-repair managed runtime
